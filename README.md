# Transparent Algorithm App

A Next.js 15 demo app that simulates a social feed with transparent ranking, engagement analytics, and admin controls.  
Includes:
- **Homepage** with marketing copy and CTA
- **Dashboard** with algorithm transparency panels, feed, and analytics
- **Auth system** (localStorage-based with login, signup, and logout)
- **UI components** built with TailwindCSS, Radix UI, and shadcn
